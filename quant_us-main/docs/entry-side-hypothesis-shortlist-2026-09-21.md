## 0. 前置：两条会决定所有判定的口径

**① 通过率低不是过滤无效的证据。** 010 的漏斗条件通过率是
`ranking 44.51%` / `daily 22.54%` / `weekly 63.70%` / `market 80.80%`。
一个**选择性**的过滤器本来就该拒绝大多数 —— 这几条数字**不携带"该不该保留这道门"的信息**
（§5.2 要求报它们，但报它们是描述，不是判决）。唯一能判的是**消融对照**：只移除该门、
保留其余规则，并且**两个方向都统计**（被它挡掉后赚钱 / 被它挡掉后亏钱）。
本清单里没有任何一项以"通过率低"作为立项理由。

**② 机会级收益差不能相加当组合增量**（§5.4）。三项假设的第 1 步都只回答
"这道门本身有没有信息"，账户级要另做，因为它会通过现金、槽位与后续机会的路径依赖改变结果。

## 1. H-A：入场等待是否导致追高（"确认的代价"）

| | |
|---|---|
| **机制** | B3 要求月排名 ≤5、市场门开、周线上行、**日线突破/回踩**四道并集，且在信号日的**次日开盘**入场。确认步骤可能系统性地买在更高的价格：用"入场价相对决策日/周线门开启日收盘的溢价"换取"入场后更小的不利波动"。两者谁大谁小，是纯经验问题。 |
| **已有证据** | 有：`weekly` 通过 2041 行、`daily` 通过 460 行，每行的 `feature_values.daily` 记了当日信号明细（突破/回踩条件值），`funnel_observations.json` 有逐 session 观察；入场价在账本里；决策日收盘价在冻结价格里。**没有**：两者之差（"确认溢价"）从未算过；也从未做过"周线门开启首日就入场"的反事实。 |
| **唯一改动** | 把"周线门 + 日线突破/回踩"替换为 §8.3 已定义的**简化入场**：等待窗内首次 `close > MA20`，T+1 开盘执行。月排名、市场门、等待窗、H60、费用、五档上限全部不变。 |
| **对照口径** | 同一批候选轮次、同一市场门与等待窗。两臂**共用同一条价格路径**；股数按各自止损距离重算以**维持原单笔风险预算**（与 H3 同一纪律）。机会级总体取**两臂都会入场的候选**，另单列"只有 A 入场"与"只有 B 入场"两批（§5.4 两个方向）。 |
| **主指标** | ①确认溢价：入场价 / 决策日收盘 − 1（%，并折算为 R）；②入场后 MAE（%与R）；③持有期。账户级另看全成本终值收益差与 MDD 差。 |
| **风险门槛** | 溢价与 MAE 必须**联合**判读（MAE 变小但溢价更大 = 用价格换确认，要算净账）；机会级增量不集中（单一证券 ≤50%，剔除后仍为正）；2× 费用下仍为正。 |
| **停止条件** | 若简化入场在机会级同时**溢价更高**且 **MAE 更差** ⇒ 日线确认是净贡献，保留原规则；增量集中在少数标的 ⇒ `CONCENTRATED` 保留；两臂无实质差异 ⇒ `NO_IMPROVEMENT` 保留。 |
| **通过后账户级验证** | 同引擎（`paper_engine.step`：真实现金、T+1、公司行动、五仓、回撤阶梯、单笔风险预算）同起点重放两臂；比终值、MDD、暴露、**被挤掉的机会清单**；MDD 差 ≤ 0.03；2× 费用下仍为正。之后才冻结单项 challenger + 前向窗口。 |

**影响覆盖**：460 个 READY 候选全部受影响（`daily` 是必经之门）；**独立样本**：460 个候选轮次，
按证券×轮次去重后仍充足；**实现风险**：中（需要复刻"首次 close > MA20"的等待窗语义，
但 §8.3 已给出定义）；**能否产生改动**：能。

## 2. H-B：等待窗是否错过有效趋势（过期后才出现的信号）

| | |
|---|---|
| **机制** | 等待窗 = 决策日之后 **20 个 session**。窗口内没出信号、窗口过后才出信号的候选，那一段趋势被完全放弃。问题：那些"过期后"的信号，扣费后是否仍有优势？若有，说明 20 这个长度在**丢弃**有效机会；若无，说明它守住了"信号必须新鲜"的纪律。 |
| **已有证据** | 有：**50 个候选**终态为 `EXPIRED`（`funnel_observations.json` 里有 `WAIT_WINDOW_EXPIRED` 与 `max_wait_sessions: 20`），逐 session 的 `weekly`/`daily` 观察可定位"过期后首个信号日"；价格与费用口径齐备。**没有**：过期后信号的后果从未算过。 |
| **唯一改动** | 等待窗从 20 放宽（预登记时**只登记一个**值，例如 40），**其他一切不变**。注意它改的是"入场时点能不能继续等"，不是入场条件。 |
| **对照口径** | 用户明确要求：**只比较相同可观察期限，避免成熟度偏差**。具体做法：两臂都用 H60 同一持有期口径；只把**两臂都已成熟**的样本放进比较（过期后信号天然更晚，若不设同一成熟门，它会显得"还没走完"，或被截断在数据末端）；未成熟/被数据末端截断的单列右删失比例。另外，放宽等待窗会让候选更晚入场、可能与**下一轮**候选竞争同一份现金与槽位 —— 这部分**不在机会级**，属账户级。 |
| **主指标** | 过期后信号的机会级净 R（扣费）与"相同时点上窗内入场"的样本分布；被放弃的趋势占账户收益的比例（描述）。 |
| **风险门槛** | **样本量优先**：先算"过期后真的出现了信号且已成熟"的独立组数，不足 30 即 `INSUFFICIENT_SAMPLE`；增量不集中（≤50%）；2× 费用下仍为正。 |
| **停止条件** | 样本不足即停（**不为了完成项目放宽口径或将就**）；改善集中在少数标的 ⇒ 保留；2× 费用下转负 ⇒ 保留。 |
| **通过后账户级验证** | 同引擎重放 20 vs 放宽后的等待窗；重点回答"是否挤掉后续机会"（`MAX_POSITIONS`/`DUPLICATE_ACTIVE_SECURITY` 的拒绝数变化 + 被挤掉的机会清单），以及 MDD 差 ≤ 0.03。 |

**影响覆盖**：仅 **50 个**候选（占 1588 个轮次的 3.1%）；**独立样本**：最弱 —— 需先做样本量筛查；
**实现风险**：低；**能否产生改动**：能，但**很可能先撞样本不足**。

## 3. H-C：排名边界是否过于敏感（第 5 名 vs 紧邻落选）

| | |
|---|---|
| **机制** | `top_n=5` 把月度排名硬切在第 5 名。若第 5 名与紧邻落选者（rank 6、7…）的后续表现**没有稳定差异**，说明排序在这个边界上不携带信息 —— 那"取前 5"这个动作的边际信息量很小；若差异稳定存在，则排序是有效的。 |
| **已有证据** | 有：`ranking` 阶段 **642 行 `BELOW_TOP_N`，且每一行都带 `feature_values.rank`**（实测 rank 6…13 各约 103 个 = 每轮 8 个落选 × 103 轮）；价格、费用、H60 口径齐备。**没有**：`RULE_REJECTED` 的行**没有任何收益字段** —— 落选候选的后续表现**从未算过**，这是本项要新建的全部计算。 |
| **唯一改动** | **不改任何规则。** 本项是**纯诊断（measurement）**，产出是"排序在边界处是否携带信息"的证据。 |
| **对照口径** | 同一轮次内、**同一可观察期限**、同一费用与 H60 口径；以 rank 为序数比较各 rank 桶的后续净 R 分布（看整个分布与区间，不看最好的一桶），并跨轮次/分年/市场阶段复核符号是否稳定。 |
| **主指标** | rank 桶之间后续净 R 的**配对区间**（时间块重采样），以及"rank 5 与 rank 6+ 的差异是否跨年同号"。 |
| **风险门槛** | 差异必须**跨轮次稳定**且不由少数标的贡献（≤50%），否则一律读作"边界无稳定信息"。 |
| **停止条件** | 无稳定差异 ⇒ 结论是"排序在边界无信息"，**据此不改任何规则**；**尤其不得据此扩大 `max_positions`**（用户明确禁止：第 5 名与第 6 名无差异 ≠ 应该多买）。 |
| **通过后账户级验证** | **不适用**。本项不产生改动，故没有 challenger 可冻结；若它指向"排序无信息"，正确动作是**另立一个新的排序假设**并单独预登记，而不是把仓位数放大。 |

**影响覆盖**：紧邻边界的落选候选（rank 6/7 各约 103 个）；**独立样本**：本清单里最强（数百个）；
**实现风险**：低（只需价格路径与费用）；**能否产生改动**：**不能** —— 它是"支持现状或指向新假设"的证据。

## 4. 横向对比与选择标准

| | 影响覆盖 | 独立样本 | 实现风险 | 能否产生改动 |
|---|---|---|---|---|
| H-A 确认的代价 | 460 个 READY（大） | 充足 | 中 | 能 |
| H-B 等待窗 | 50 个 EXPIRED（小） | **最弱，需先筛查** | 低 | 能，但可能先撞样本不足 |
| H-C 排名边界 | 约 206 个紧邻落选 | **最强** | 低 | **不能** |

**选择标准**（§8.2：不能只按最大历史利润选）：**可执行收益差的可能性 × 影响覆盖 × 独立样本 × 实现风险**。

**我的建议：H-A 优先预登记。** 理由：它的改动**已被设计 §8.3 明确定义**（不是我在清单里临时发明的）、
影响覆盖最大（`daily` 是必经之门，460 个候选全受影响）、样本充足、且它直接检验本次 review 里
最实质的一个问题——**日线确认到底买到了确认还是只买贵了**。H-B 我建议**先只做样本量筛查**
（便宜，且若不足就地结束，省下一次完整诊断）；H-C 只有在"打算改排序"时才值得做，
否则它只能得出"保留现状"或"另立新假设"两种结论。

## 5. 无论选哪个都适用的门槛（预登记时逐条落数）

- 机会级：净增量为正；不集中（单一证券 ≤50%，剔除后仍为正）；2× 费用下仍为正；
  控制项（未被改动的部分两臂必须完全相同）不过 ⇒ `ENGINEERING_BLOCKED`，不出研究结论。
- 账户级：净增量 > 0；`abs(MDD差) ≤ 0.03`；2× 费用下仍为正；最差单笔 `net_R` 不劣于基线。
- 验证：历史窗口（含 010 的 `2015-01-02→2026-08-31`）**已被查看，只能用于定位问题**；
  正式资格来自事先登记的前向窗口（≥30 独立成熟组 且 ≥60 交易日）。
- 记录：全部尝试计入试验登记，**失败不删除**（§9.2）。

## 6. 本清单明确不做的事

- 不跑多套收益结果再挑赢家；**最终只会有一个**假设进入预登记。
- 不把"通过率低"当成过滤无效的证据；不做没有消融对照的规则改动。
- 不把机会级收益差当组合增量；不用"止损后反弹"这类描述当证据。
- 不据此扩大 `max_positions`、不加入追踪止损、不调整 H60。
- 容量侧不动：`DUPLICATE_ACTIVE_SECURITY` 拒绝不等于错失收益，现金占比高也不能直接归因于仓位上限。
- 不重开 H3（已按登记判定为 `CONCENTRATED`）。
