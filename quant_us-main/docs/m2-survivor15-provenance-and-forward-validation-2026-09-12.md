# 15只存续股票来源核验与前向验证登记（2026-09-12）

## 本地来源核验结果

对 `research_quality_intervals-v3.csv` 放行的15只，使用归档的 Futu basicinfo 原始响应、主数据 v2、symbol_history、39,182行不复权日线、公司行动表及价格行动检查表，运行 `scripts/data/audit_futu_survivor_provenance.py`。最终不可覆盖产物在本机 `data/m2_raw_audit/M2-SOURCE-CHECK-20260912-003/`；`summary.json` 含七个输入 SHA-256，`security_provenance.csv` 逐证券列出 Futu `stock_id`、上市日、首根 bar、行动检查和时点缺口。

结果：**15/15 本地来源链一致**。证券代码与主数据、ticker 映射一对一，Futu 报告上市日不晚于首根 raw bar；行动价格检查没有窗口内冲突。最初 META 被列为行动缺双侧价格，复核发现对应的是 **2026-09-21 尚未发生的除息日**，而本批日线截止 2026-09-10。审计工具现单列 `future_actions_without_bars`，不把未来未有行情错报为历史缺口。

这不等于历史来源时点已验证：归档的是 **2026-09-12 的当前证券目录**，15只主数据 `source_observed_at` 均空，公司行动 `source_observed_at` 也均空；仅凭当前下载结果无法证明每个历史决策日当时已可获得该字段。上市日期可用于“入样日未早于 Futu 报告日期”的一致性检查，但仍保留 `reported_unverified`，不升级为独立历史核实。既有存续样本边界及 ORCL/QCOM/TSM/UNH 行动历史隔离保持不变。

## 前向独立验证协议

历史 2016-01-01 至 2026-06-30 的15只矩阵已经被查看，只能用于工程诊断。**独立验证从本文件及代码冻结后的首个美股交易日开始，使用随后真实新增的 Futu 日线，不回填旧日线冒充未见数据。**冻结时记录 commit、配置和15只清单哈希、Futu 原始响应归档路径、原始价与行动版本；样本只含当前15只存续普通股，不能中途按收益增删。现有工程 Manifest `formal=false`，不得改名当成前向结果。

1. **固定决策与成交。**沿用当前 `raw_asof` setup、T+1 不复权开盘、T−1 原始价流动性、逐日质量门和 A/B/C 嵌套定义；D 因缺历史时点标签保持 `inconclusive`。退出沿用 E1–E11 和40交易日最长观察窗，费用情景固定为总交易成本 0.1%、0.2%、0.5%、1.0%；不根据前向结果调参数。
2. **固定观察窗口。**连续收集冻结后六个自然月产生的全部合格 setup，随后再等最长40个交易日让退出观察窗到期。数据缺失、行动未解析、右删失与拒绝原因都留在原分母；未到期时只报告覆盖和缺失，不提前报告胜负。
3. **预定主要比较。**以 E5（初始止损、最多20交易日）和总成本0.2%为唯一主要切片，比较 C 与 A 的独立组平均 `net_pnl_pct`；同一证券×策略×周为一个重采样组，按现有报告脚本做联合 bootstrap，给出差值与95%区间。同时并列报告 A/B/C 的候选数、成交参与率、质量拒绝、每笔净回报、组合约束后的收益/回撤、证券和月份集中度。C 是 A 的过滤子集，不能把同一 setup 的成交收益差误解释为过滤增量；组合层结果必须与条件成交均值一起看。
4. **次要敏感性。**E1–E11 × 四成本全部展示，但不得在看结果后改选“主方案”。按证券、月度、行动日与非行动日分层，报告右删失和独立组数。多重比较只作探索，并使用已有 Holm 校正输出。
5. **判定门。**若主要切片任一组少于100笔已到期交易、少于30个独立周组，或超过5%候选因资料缺口无法判定，结论固定为 `inconclusive`。达到样本门后，只有 C−A 的95%联合 bootstrap 区间下界大于0、组合层方向一致，才记为“前向样本支持继续研究”；否则记为“不支持”或“区间跨零、未定”。此判定不授权实盘资金。

执行前须另建不可覆盖的前向 run-id 与 Manifest，确认本协议、代码和原始输入在首个前向决策前冻结。每交易日归档原始响应与决策时间戳；若新 Futu 数据因时间、公司行动或代码映射异常无法回放，当日标为质量失败，不事后静默修复并计入成功样本。
