## 0. 披露：这份登记**不是盲的**

假设由用户指定，但立项依据里含我已看过的汇总：010 的漏斗通过率、退出分类、账户指标，以及

登记固定的不是"盲"，而是**改什么、怎么算、什么算通过、门槛多少**。

## 1. 假设

> **保留周线门、移除日线确认，能否改善扣费后的入场收益，同时不显著恶化不利波动与左尾损失。**

- **「确认溢价」只是机制指标。买得更便宜本身不算成功**；成功只能由扣费后收益与风险门槛共同判定。
- **竞争解释**：日线确认可能在买贵的同时**避开了坏路径**（更小的 MAE、更少的止损、更薄的左尾）。
  若收益差为正而风险门槛任一不过，结论是"**用风险换收益**"，不是改进。

## 3. 执行口径

- **止损**：沿用原规则 `max(8% × 入场价, 2.5 × ATR14)`，**各臂用自己信号日可得 ATR**（含 `scale_to_next`）。
- **定仓**：两臂都按**原单笔风险预算**（`single_position_risk_bp = 100`）：股数 = 风险预算 / 各自止损距离
  ⇒ 止损距离不同则股数不同，但**承担的风险相同**。
- **退出**：H60（各自入场日起 60 个 session 收盘退出；数据不足则右删失）。
- **费用**：单边 10bp（往返 0.2%）；压力情景单边 20bp。
- 公司行动按冻结输入同一口径；无追踪止损、无提前退出。

## 6. 判定先锁定

### 主指标

配对 `Δnet_R = net_R(实验) − net_R(基线)`，其中 `net_R = 扣费后损益 / 冻结的初始风险金额`
（两臂各自"止损距离/入场价"为分母 ⇒ 同口径）。**用净 R 而非净收益率**：两臂股数不同，
用收益率比较会把"风险暴露不同"混进结论；净收益率(%)作必报辅助。

区间：配对时间块重采样，**20 session 块、2000 次、固定种子**；10/40 session 作敏感性
（块长不按最好显著性选择）。**通过 = 点估计 > 0 且 95% 区间下界 > 0。**

### 必报辅助

两臂 MAE_R 与 MAE% 分布；止损出场率与跳空止损笔数；左尾（`net_R < −1R / < −2R` 的笔数与占比、
最差 5 笔之和）；持有期与退出原因分布；**确认溢价**（入场价/决策日收盘 − 1、入场价/周线门首次
满足日收盘 − 1，以 % 与 R 表示）；两臂入场日相隔多少 session；仅实验侧那一批的笔数与净 R 分布；
**1× 与 2× 费用下的全部主/辅指标**。

### 风险门槛（**绝对值是判断值，不是从数据推出来的；写在这里就是为了不被事后调整**）

| 类别 | 门槛 |
|---|---|
| 样本量 | 配对 ≥ 30 组；仅实验侧 ≥ 30 组；≥ 60 交易日。不足则该类只作描述并标 `INSUFFICIENT_SAMPLE`，**不为凑样本放宽截止日或口径** |
| 左尾 | 实验臂止损出场率 ≤ 基线 **+10pp**；`net_R < −2R` 占比 ≤ 基线 **+3pp**；最差 5 笔之和不得劣于基线 |
| 不利波动 | 配对 MAE_R 中位数差（实验 − 基线）的 **95% 区间上界 ≤ +0.10R** |
| 集中度 | 配对增量单一证券 ≤ 50%，剔除最大贡献后仍为正；仅实验侧那一批也不得由单一证券主导 |
| 成本压力 | 2× 费用下单边 20bp 时 `Δnet_R` 仍为正 |
| 两方向 | 必须同时报"基线错过、实验侧赚"与"基线避开、实验侧亏"两类的笔数与金额（§5.4） |

### 判定令牌

`SUPPORTED`（主指标 + 全部风险门槛通过 ⇒ 进账户级）· `NO_IMPROVEMENT` · `RISK_REJECTED`
（收益改善但风险门槛不过 = 用风险换收益）· `CONCENTRATED` · `INSUFFICIENT_SAMPLE` ·
`ENGINEERING_BLOCKED`。

### 控制项（不过即 `ENGINEERING_BLOCKED`，不出研究结论）

1. **A 臂必须复现 010 的成交**（入场日、入场价、股数、止损）——不一致即实现有误，先修再算；
2. 两臂都不得用信号日收盘成交；
3. 成熟度一致：任一臂被数据末端截断的候选不得进入配对，只能进"右删失"单列。

### 账户级（**仅在机会级 `SUPPORTED` 之后**）

同引擎（`paper_engine.step`：真实现金、T+1、公司行动、五仓、回撤阶梯、单笔风险预算）同起点重放两臂。
主指标 = 共同起止日**全成本终值收益差**（§9.1）；门槛 = `abs(MDD差) ≤ 0.03`、2× 费用下仍为正、
最差单笔 `net_R` 不劣于基线。**必须回答**：实验侧更早入场是否**挤掉后续机会**
（`MAX_POSITIONS` / `DUPLICATE_ACTIVE_SECURITY` 拒绝数变化 + 被挤掉的机会清单）。

## 8. 禁止

看结果后调整任何门槛/截止日/块长/口径；同窗口反复重试直到出现赢家；只报配对不报仅实验侧、

在同一次诊断里加入第二个改动（追踪止损、H60、仓位数）；据此扩大 `max_positions`。
