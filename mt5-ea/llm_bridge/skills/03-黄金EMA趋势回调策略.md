# 黄金 EMA 趋势回调策略（描述式规则 · XAUUSD · M1）

优先级：本技能给出具体入场/离场规则，与《盘面分析方法》冲突时以本技能的明确条件为准；任何情况下不得违反《交易纪律与风控》。

## 数据基础（只能使用快照中出现的数据）
- FASTMA / SLOWMA：EA 当前参数下的快慢 EMA（默认 EMA10 / EMA30），取当前未收盘K线的值
- K-1 ~ K-n：最近 n 根已收盘K线（OHLC，按时间从旧到新，K-1=最新一根已收盘）
- BID/ASK/SPREAD、LOCAL_SIGNAL（1=最近两根收盘K线金叉，-1=死叉，0=无交叉）、POSITION/POSITION_*/BALANCE/EQUITY
- 快照里没有的数据（大周期K线、时间、新闻、成交量）一律不得编造或假设；缺数据就 hold。

## 1) 趋势过滤（不满足直接 hold）
- 多头趋势：SLOWMA < FASTMA，且 BID > FASTMA > SLOWMA（价格站在快慢线之上）
- 空头趋势：SLOWMA > FASTMA，且 BID < FASTMA < SLOWMA（价格压在快慢线之下）
- 价格夹在两线之间、两线缠绕或间距过小：方向不明 → hold

## 2) 开仓规则（只顺趋势，做多/做空完全对称）
### 做多必须同时满足（缺一即 hold）
1. 多头趋势成立；
2. 出现过回调：最近 2~4 根已收盘K线中至少一根阴线，且低点下探到 FASTMA 附近（允许轻微刺破，但不能收盘远离 FASTMA 下方）；
3. 止跌确认：最新已收盘K线 K-1 收阳（close>open），低点不低于前一根低点，收盘回到 FASTMA 上方；
4. LOCAL_SIGNAL ≠ -1（最近无死叉，避免接下跌中的刀）；
5. 持仓检查：无持仓，或只有同向多头持仓（有持仓不重复开仓）；若持反向空单，先建议 close，不直接建议 buy，等人工确认后再等下一个完整信号；
6. 能给出有结构的 SL/TP（见下），否则 hold。

做空与做多对称：回调=反弹至 FASTMA 附近出现阳线（多头场景为阴线）——即 K-1 收阴、高点不高于前一根高点、收盘回到 FASTMA 下方。

### SL/TP 与手数
- SL：放在最近 5 根已收盘K线的显著极值之外（做多=最低点下方，做空=最高点上方），并留出缓冲。缓冲至少覆盖当前点差（SPREAD 点 × 0.01 美元）+ 滑点余量，通常取最近 5 根K线平均振幅的 10%~30%；
- TP：优先取前方最近的关键位（前高/前低、整数关口、K线密集区），且止盈距离 ≥ 1.5 × 止损距离（盈亏比至少 1:1.5）；
- 方向校验：buy 必须 SL < 当前价 < TP；sell 必须 TP < 当前价 < SL；算不出清晰位置就 hold；
- lot_size 统一写 0.01：EA 会按账户风险比例自动换算实际手数，不要自行放大。

## 3) 持仓管理（每根K线都检查）
- 持仓逻辑仍成立：默认建议 hold，让 EA 挂的 SL/TP 自动运行，不频繁手动平仓；
- 多头持仓趋势被破坏：K-1 收盘跌破 SLOWMA，或收盘跌破开仓时设定的止损位/最近 5 根K线低点 → 建议 close；
- 空头持仓对称；止损触发后不立即反手，等下一个完整信号；
- 出现与持仓方向相反的明确结构（如持多单时出现死叉且跌破 SLOWMA）→ 建议 close，绝不加仓摊平。

## 4) 禁止情形（一律 hold）
- 单根长阳/长阴后直接追单（没有等回调确认）；
- SPREAD 明显偏大（显著高于近期常见水平或接近系统上限）；
- K线数据不足（少于 6 根已收盘K线，或缺 FASTMA/SLOWMA）；
- 同一根K线已经给过建议，或刚执行过同向操作。

## 5) 输出要求
- confidence：条件全部干净满足时 0.7~0.85；有任何凑合/模糊情况给 ≤0.5 并 hold；
- action=close 时 stop_loss/take_profit 填 0；
- reason 必须写清：趋势方向 → 回调/确认方式 → SL/TP 依据，例如“EMA快线上穿慢线后回踩快线收阳止跌，SL 前低 2631.20，TP 前高 2642.80，盈亏比约1.6”；
- 只输出一个 JSON，不得输出其他文字。
