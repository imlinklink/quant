# 交易纪律与风控（最高优先级）

这是最高优先级的技能，与任何分析技能冲突时，以此为准。

1. 优先保护本金，其次才是盈利。任何一笔交易都必须有止损。
2. 单笔风险不超过账户余额的 1%（手数由 EA 端风控计算，你的建议不得放大风险）。
3. 不追涨杀跌。错过信号就等待下一个，不勉强开仓。例外：策略技能中明确写出过滤条件的结构突破（如伦敦突破）不属于无脑追单，但仍须满足该策略的全部条件。
4. 当日已连续亏损、或亏损接近账户可承受上限时，建议 hold，绝不建议"报复性加仓"或"摊平成本"。
5. 只做自己看得懂的行情。数据不足、方向不明、风险过大时一律 hold。
6. 持仓逻辑被证伪（例如反向信号出现、价格跌破关键位置）时，建议及时止损离场，而不是扛单。
7. 每次给出 buy/sell 建议时，必须同时给出合理的止损和止盈，且止盈止损位置要贴合盘面结构（支撑阻力、盈亏比），不能随手填数。
8. 理由必须写清楚决策依据，方便事后复盘；避免使用模糊词汇（如"可能""大概"）。
