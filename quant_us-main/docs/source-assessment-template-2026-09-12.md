# 历史证券数据源评估（模板）

> 依据 `historical-universe-and-evidence-handoff-technical-design-2026-09-12.md` §2.3：评估数据来源是否**实际提供**下列能力，并记录许可。**当前 Futu 目录只用于当前存续证券交叉核对，不能承担退市补全。**

状态：**未决**（未确认可用来源前，阶段 2–5 的真实数据管道无法推进；本仓库内无覆盖退市/ticker 变更/公司行动的来源。）

## 1. 能力核对（每个候选来源各填一份）

| 能力 | 是否提供 | 证据 / 字段 | 备注 |
|---|---|---|---|
| 历史退市证券 |  |  | 必须能拿到退市样本，否则结论只能 inconclusive |
| ticker 变更历史 |  |  | 支撑 `symbol_history` |
| 历史上市/退市日期 |  |  | 支撑 `listed_at/delisted_at` |
| 公司行动（拆股/反向拆股/股息/并购/分拆/退市结算） |  |  | 支撑 `corporate_actions` |
| 历史日线（含原始可交易价） |  |  | 执行价不能用前复权冒充 |
| **下载权** |  |  | 是否允许批量下载 |
| **长期保存权** |  |  | 是否允许本地归档原始响应 |
| **研究用途许可** |  |  | 是否允许用于策略研究 |
| 时间字段可审计性 |  |  | `published_at` / `observed_at` 是否有来源证明 |

## 2. 结论

- 来源名称 / 版本：
- 判定：`通过 / 不通过`
- 若通过：原始归档路径 `data/source_archive/<source>/<run-id>/`，`master_version` = ______
- 若未通过：缺少的能力与影响。
