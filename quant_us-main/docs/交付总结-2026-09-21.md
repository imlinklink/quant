## 0. 项目目的（用户口径，2026-09-21 明确）

**主线 = 三个目标：**

1. **筛选更有效的买入、卖出策略。**
2. **提升 LLM 在完整决策链条中的实际贡献。**
3. **在控制回撤和尾部风险的同时，提高胜率与扣费后收益。**

**约束**：工程修复与实验验证都**服务于**这三个目标，**不能长期停留在基础设施建设**。

**保留的非目标：不接入公司事件源**（设计 §3.2）。这是刻意的，不提议去接。
后果必须承认：LLM 当前只能拿到**市场级证据**（`security_id='MARKET'`，来自每日市场日报），
公司级事件恒为 0 条 ⇒ 所有 LLM 判断的适用范围是「**市场证据驱动的决策**」，
**不得**外推为公司基本面判断能力。目标 2 要在"只有市场级证据"这个前提下做成。

**四个数**（三个目标共用）：**收益（扣费后）· 胜率 · 最大回撤 · 尾部风险**。
任何结论必须落到这四个数上；"完成了 N 个模块 / N 份文档"**不算推进**。

| 目标 | 判据（怎么算推进了） | 不算推进 |
|---|---|---|
| 1 策略 | **前向**窗口上胜率与扣费后收益优于冻结父策略 | 回测数字涨；历史窗口再切一刀 |
| 2 LLM 贡献 | `path_changed` / **L−R 净值差** / `applications_written` —— 模型的话**真的改变了成交**，且值这个改动 | 调用成功 N 次；L ≡ R；权限仍全 shadow |
| 3 风险调整后收益 | 胜率↑、扣费后收益↑ **同时** MDD 与尾部不恶化 | 用风险换收益；只看 CAGR |

## 1. 度量手段

### 1.1 终态度量（三个目标共用）

**收益（扣费后）· 胜率 · 最大回撤 · 尾部风险**——见 §0 的四个数。下面两层是**量这些数的工具**：
目标 1 用三层尺子（§1.2），目标 2 用 R/L 配对（§1.3）。目标 3 不另建工具，它读的是同两套数里
的**回撤与尾部**分量。

### 1.2 目标 1（策略）——三层尺子，逐层立起来才敢往上走

这一层的设计理由：**先在不可信的测量上优化是白费**。所以顺序是硬的。

| 层 | 度量什么 | 怎么判过 | 现状 |
|---|---|---|---|
| **① 执行尺子** | 实盘/联调**真的按预期跑通**了吗 | 作业按预期触发、退出码与账本核对、账本不变量 | 已立（见 §2.1） |
| **② 回测尺子** | 回测**可复现、口径一致**吗 | QQQ 同口径基准（原始价 + 官方分红表，**不用 qfq**）；跨引擎对账 `TOLERANCE_USD = 0.0` | 已立：`baseline_parity` 实测 **2631 个会话逐日零分歧** |
| **③ 前向验证** | 策略优势**在样本外还在不在** | 见下 | **唯一正式资格；2026-09-21 启动** |

**第③层（前向）的具体口径** —— 登记 `B3-FORWARD-20260921`，三臂只差宇宙：

- **主指标**：共同起止日的**全成本终值收益差**（B − A，以及 B − C）。
- **必须同时报告**：最大回撤及其差、年化波动、平均/最大暴露、换手、成交笔数、现金使用、
  盈亏贡献集中度、未完成交易与右删失、数据质量、退化配对（单列）。
- **评估点**：同时满足 **≥30 个独立成熟组** 且 **≥60 个交易日**的**首个**时点；
  **只判定一次**；跨零即 `INCONCLUSIVE`，**不得**延长窗口直到显著。
  独立成熟组 = **已入场且已到期**的 (证券 × 候选轮次)。按历史成交速率（17.9~18.9 笔/年）
  ⇒ **≈19 个月**（预期，非承诺）。
- **门槛**：主收益差为正 **且** 配对差异 95% 区间下界 > 0 **且** 双倍成本下仍为正 **且**
  `abs(MDD差) ≤ 0.03` **且** 单一证券正贡献 ≤ 50% 且 leave-one-out 后仍为正。
- **不自动晋级**：达门槛也不改变任何生产权限或配置。

### 1.3 目标 2（LLM 实际贡献）——度量"作用"，不度量"调用"

这一层的设计理由：**调用成功 ≠ 起了作用**。所以度量分两套数：**模型有没有参与**、
**执行上发生了什么**，两者不得互相冒充。

**核心机制：R / L 配对账户。** 同一批机会，**R 走纯规则**、**L 同一条规则 + LLM 覆盖**。
`paired_performance` 输出 L 与 R 的全成本收益差、MDD 差、暴露差，以及 VETO / ABSTAIN 计数。
**L ≡ R 时，这条轨一格没动。**

**三个直接判据**（看这三个，不看调用成功率）：

| 判据 | 含义 |
|---|---|
| `path_changed` | 模型的话**有没有改变执行路径** |
| L 与 R 的净值差 | 改变之后**值不值** |
| `applications_written` | 有没有真的落成账目（而非只留痕） |

**三项覆盖率/影响率指标**（`report.py::entry_metrics`，设计 §8）——分母一律是
「**该有判断的对象**」，不是"碰过的对象"；分母为 0 时返回 `None` 而非 0
（"没有对象可评" ≠ "评了但全放行"）：

- `real_review_coverage` —— 有效真实评审覆盖率（**夹具评审绝不计入**，否则会用假数字冒充已接入真实模型）
- `plan_change_rate` —— 实际交易计划改变率（分母 = **模型真正参与过**的应用）
- `trackable_completion_rate` —— 决策到执行可追踪完成率
- 配套披露：`veto_unapplied`（已冻结但未落执行）、`market_only_applications`（**仅由市场级证据**支撑的判断）

持仓侧另有 `report.py::position_metrics`（口径纪律相同）。

**晋级判定** `decision_ledger/promotion_review.py`：从账本算输出有效率、硬风控越权、
不可重放、可区分性等；**算不出来的一律 `None` → `unavailable` → 拒绝晋级**（fail-closed）。
权限等级默认**全部 shadow**。

### 1.4 明确"不算推进"的清单

- 增加文档、登记、守卫、测试 → **不算**（它们是防自欺的配套，不是产出）。
- 模型调用成功 N 次 → **不算**（要看 `path_changed` / L−R）。
- 回测数字涨了 → **不算**（要看前向）。
- 历史窗口上再切一刀 → **不算**（那段已被反复查看）。

三次单项诊断**同一个形态**：任何单条规则的"改进"都由 1–2 只标的决定。原因是**结构性**的——
13 只硬编码的十年赢家池 × 月度前 5 ⇒ 单门消融的受影响子集只有几十个候选，单一标的自然
权重就是两位数百分比 ⇒「单一证券 ≤50%」**近乎不可通过**。

**参考数字（历史窗口，已被查看，不得外推）**：冻结父策略 B3@60@1.0pct =
CAGR 15.16% / MDD −13.90% / Calmar 1.09 / Sharpe 1.22 / **胜率 53.7%** / top1 赢家占比 9.3% /
**对 QQQ 超额 −4.3%**（即：**跑输同口径 QQQ**）。

### 3.2 目标 2 · LLM 实际贡献：**作用为零**

机制齐全（R/L 双账户、entry-veto 三态、position overlay、权限等级、晋级判定、日报），
但：**权限默认全 shadow ⇒ 校验通过的决策也不改变执行路径**；且在证据不足时质量门短路
⇒ 模型根本不会被调用 ⇒ **L ≡ R**。设计 `llm-full-loop-decision-design-2026-09-19.md` §18
七条完成定义里，审计时**只有第 6 条（LLM 失败时规则主链继续）真正达成**。
正式前向实验 `M1-FORWARD-S-20260917` 至今 `shadow_job_runs = 0`、`llm_decision_runs = 0`，
**从未有过一次真实模型决策**（该账本里有 `shadow_applications = 2` —— 那是 R 侧规则成交，
不是模型决策；`fixed_pass` 的 L 侧同批成交，两者相同）。

### 3.3 目标 3 · 风险调整后收益：**有测量、无改进**

这一条**从来没有被当作独立目标打过**——历史上所有诊断都是在"收益"这一个维度上做的。
现有的与回撤/尾部相关的**已知事实**：

- **冻结父策略**（历史窗口，已被查看）：CAGR 15.16% / MDD −13.90% / Calmar 1.09 / 胜率 53.7% /
  **对 QQQ 超额 −4.3%（跑输）**；平均暴露仅 ~35%（现金长期闲置）。
- **止损确实在控尾部**（H3 顺带证明，这是它最有价值的一条）：含止损最差单笔 **−1.87R、0 笔低于 −2R**；
  关掉止损后最差 **−5.54R、13 笔低于 −2R**。所以"关掉止损换收益"是把左尾掀开，不是改进。
- **回撤阶梯**（`portfolio_shadow/risk_policy.py`：10/15/18/20% → REDUCED / PAUSED_ENTRY /
  REVIEW_REQUIRED / LIMIT_BREACH，带迟滞恢复）**只存在于影子引擎**，历史引擎没有这个概念——
  它被 `baseline_parity` 明确点名为"没有第二实现、未对账"的组件之一。
- **风险预算的呈现有歧义**：实测"上限 500bp / 实际均值 519.7bp / 峰值 1985.6bp"。这**不是超限**
  ——500bp 是**入场瞬间**的预算，而 `risk_used = Σ shares×(close−stop)` 随价格上涨漂移
  （除息下调止损会再加宽距离）。但报告把两者并列容易被读成超限，**且这个数正是"影子引擎没有
  追踪止损"那条缺口的证据**——这是目标 3 的一个现成入口。

**结论**：目标 3 目前既没有独立的度量口径，也没有任何被证据支持的改进。前向登记里唯一相关的
门槛是 `abs(MDD差) ≤ 0.03`（回撤预算）。

### 3.4 净结果

**三个目标都没有产出正向结果。** 这一段工作的产出不是收益，是**防止自欺**——
把三个原本会让人相信的数字变成了"不可信"或"其实是押注"：基准曾经是错的、
13 只池子的优势是后视挑出来的、那优势其实是行业押注。

**代价**：它不产生收益，而且真正的答案只能等前向时钟——那件事 2026-09-21 才刚按下。
