# 加入期权：辅助股票买点判断设计

更新时间：2026-09-09  
适用工程：`quant_us-main`

## 1. 目标

系统不交易期权。期权链只提供市场对波动、事件风险和尾部保护的定价证据，辅助 LLM 完成股票研究排序，并在股票策略已经产生候选后帮助用户判断是否适合现在买入。

期权证据不能单独创建买入候选、提高仓位或绕过股票规则。初始阶段只展示和记账；只有固定时间点的影子评估证明某项指标对特定股票策略有稳定增量后，才允许进入降档或规则门。

## 2. 决策边界

期权层回答四个问题：

1. 市场是否在定价近期大事件或异常波动？
2. 下跌保护是否明显贵于上涨敞口？
3. 成交和未平仓结构集中在哪里？
4. 当前期权数据是否完整、及时且有足够流动性？

期权层不回答“股票一定上涨还是下跌”。`prob_of_profit` 是期权合约在给定权利金下的盈利模型概率，Delta 是局部价格敏感度，两者均不得命名为股票上涨概率。

## 3. 分层架构

```text
股票基础池
  → 股票行情、技术规则、事件与基本面证据
  → OptionViewService 获取时间点一致的期权快照
  → 程序计算 OptionView（不让 LLM 计算数值）
  → Evidence Packet 保存原始字段、质量字段和可引用摘要
  → LLM 研究排序（影子佐证）
  → 股票规则产生候选
  → 确认台展示策略相关的期权解释
  → 结果账本按 1/3/5/10 个交易日归因
```

系统保留两种能力等级：

| 等级 | 数据范围 | 允许输出 |
|---|---|---|
| `near_atm_sample` | 单到期、ATM 附近抽样腿 | ATM IV、ATM Delta、样本 OI 比；必须标明局部样本 |
| `full_chain` | 同一到期日完整 Call/Put 链 | 上述指标、全链 PCR、OI 集中价、真正的 Max Pain、覆盖率 |

局部样本不得输出全链 PCR 或 Max Pain。

## 4. 指标契约

### 4.1 第一阶段必须提供

| 字段 | 定义 | 用途 |
|---|---|---|
| `as_of` | 快照时间，含时区 | 防止未来数据和过期证据 |
| `spot` | 与期权快照对应的标的价格 | ATM 选择和结果回放 |
| `expiry_date` / `dte` | 到期日和自然日天数 | 区分 0DTE、短期和常规期限 |
| `atm_iv_pct` | 最接近现价的 Call/Put IV 均值，百分数 | 波动定价描述 |
| `atm_call_delta` / `atm_put_delta` | 最近 ATM 腿的 Delta | 敏感度描述，不能解释成概率 |
| `chain_scope` | `near_atm_sample` 或 `full_chain` | 决定哪些结论合法 |
| `n_quoted` | 成功获得报价的腿数 | 数据质量 |
| `quality` | 完整性、时效和流动性结论 | 控制 LLM 是否可引用 |

### 4.2 完整链能力

- `pcr_oi = 全链 Put OI / 全链 Call OI`，表示存量结构，不直接等价于看空。
- `pcr_volume = 全链 Put Volume / 全链 Call Volume`，表示当日活动，需要与 OI 分开。
- `oi_peak_strike` 是 Call 与 Put OI 合计最大的行权价，只描述集中度。
- `max_pain` 枚举候选结算价，选择全体合约总内在价值最小的位置。它只能在完整链上计算，并只作为临近到期的弱证据。

### 4.3 后续期限结构能力

按目标期限而不是简单取最近到期日：

- 7–14 DTE：短期事件风险；
- 30–45 DTE：主要比较基准；
- 60–90 DTE：远期基准。

由此计算 `front_iv_minus_30d_iv` 和期限结构状态。0DTE 独立标记，不进入普通阈值比较。

### 4.4 历史归一

从接入之日起保存每日快照，未来计算 `iv_percentile_60d/252d`、`iv_change_1d/5d` 及 `iv_minus_realized_vol_20d`。积累足够历史以前，不使用“该股票 IV 历史极高”措辞。不同 strike 的链内 IV 中位数不能替代历史 IV 分位。

## 5. 策略解释

### 突破策略

短期限 IV 快速上升、预期波动很大或 put skew 明显抬升时，提示事件与跳空风险。影子阶段只建议等待回踩或缩短决策有效期，不直接否定已通过的突破。

### 抄底策略

极端 put skew 或较高 PCR 只有在股票反转确认、盈亏比和高周期环境均通过后，才能作为反向佐证。它不能替代止跌确认，也不能形成“越跌越买”。

### 回调策略

期限结构平稳且 IV 没有快速上升，可作为没有显著新增事件风险的辅助证据。缺少期权数据不应自动视为利好。

## 6. LLM 输入与输出纪律

程序把数值和质量标记写入不可变 Evidence Packet，LLM 只能引用已有 evidence ID。摘要必须说明到期日、数据范围和缺失项。

LLM 可以：

- 把可靠期权证据写入 thesis、watch conditions 或 counterevidence；
- 在高事件风险下建议 `pullback` 或降低研究排序信心；
- 声明期权证据与股票趋势不一致。

LLM 不可以：

- 把 Delta、POP 或 PCR 转写为上涨胜率；
- 用局部样本推断完整链情绪；
- 因期权证据单独创建候选、决定仓位或下单；
- 在质量状态不可用时补造结论。

## 7. 数据质量门

每次快照至少记录：成功腿数、请求腿数、到期日、最后报价时间、Call/Put 是否成对、标的价格时间和失败原因。

以下情况只显示“期权视角不可用”：

- 标的价格或到期日缺失；
- ATM Call 与 Put 均无有效 IV；
- 快照超过配置允许的时效；
- 报价覆盖率低于最低要求；
- 只有单侧链却试图解释 PCR；
- 市场休市数据被误当成实时数据。

## 8. 状态与落地顺序

### P0：修正语义和契约

- 按真实 spot 选择 ATM 附近行权价；
- 区分局部样本 OI 比和全链 PCR；
- 正确计算 Max Pain，并限制为完整链；
- 删除“市场定价上涨概率”，改为 Delta 原义字段；
- 统一研究层和抄底监控器的命名及 IV 单位。

### P1：确认台展示

在抄底、突破、回调提案中显示同一份冻结 OptionView，包括到期日、ATM IV、范围标签、质量和策略相关解释。展示不改变评分、规则结果和仓位。

### P2：期限结构与快照库

三个 DTE 桶、完整链 PCR 和基础质量门已经实现。待实现预期波动、25 Delta skew，并按交易日保存快照，为历史归一和回放建立数据。

### P3：影子评估

按策略分别记录候选在 1/3/5/10 个交易日的收益、MFE、MAE、是否触发止损以及交易成本。比较同一候选集合中有无某个期权标签的差异，禁止把 LLM 选中的样本与全市场混为一组。

### P4：受约束动作

只有验证集和测试集都表现稳定、样本量充足且结论能跨市场阶段保持时，才允许从 `shadow` 升级为提示或降档。硬门需要独立配置、版本号、回放测试和一键关闭能力。

## 9. 验收标准

1. 单元测试证明 OI 集中价与 Max Pain 可以不同。
2. 局部抽样结果中不存在 `pcr_oi` 和 `max_pain`。
3. 输出不存在 `up_prob_pct` 或“上涨概率”文案。
4. ATM 抽样按行权价距 spot 排序，不依赖期权代码顺序。
5. 研究页与确认台对同一快照展示相同数值、单位和到期日。
6. 期权接口失败不会阻塞股票策略，也不会被解释为中性或利好。
7. 影子评估使用冻结时间点，不能读取候选产生后的期权数据。

## 10. 当前决策

近期保留期权视角作为影子证据。P0、三个 DTE 桶、完整链 PCR 和基础质量门已经完成；可进入确认台展示。在历史快照和样本评估完成前，不启用期权硬门，也不让期权字段直接改变交易仓位。
