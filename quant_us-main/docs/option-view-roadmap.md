# 期权市场视角 — 辅助股票买点判断的设计方案

> 本文保留最初路线背景。修正后的指标契约、数据质量门和实施顺序以
> [加入期权：辅助股票买点判断设计](options-integration-design.md) 为准；其中已经撤销
> “POP/Delta=上涨概率”和“OI峰值=Max Pain”两个旧定义。

更新时间：2026-09-09。适用基线：quant_us-main（含提交 `0ec82d0` 期权视角 P0/P1）。
对应对话共识：不用期权做交易；用期权链数据作为「市场波动/情绪/定价」温度计，辅助判断「股票现在是否适合买」。

---

## 1. 目标与边界

**目标**：对每只研究标的，由程序从富途期权链计算一栏「期权市场视角」，作为给 LLM 研究排序 / 后续规则门 的参考证据——当股票出现买点候选时，能同时看到「市场在用什么价格定价它的波动和方向」，从而更理性地决定追高、抄底还是观望。

**明确不做（防范围膨胀）**：
- 不选期权合约、不做到期/行权价推荐、不交易期权、不进券商期权下单链路。
- 不把期权视角写成「主信号」；它是过滤器/佐证，趋势与事件判断仍是主导。
- 不反向强推（不宣称期权概率=股票未来涨跌的真实概率）。

## 2. 期权数据回答什么（信号集）

| 指标 | 含义 | 对「买股票」的读法 | 局限 |
|---|---|---|---|
| ATM IV 水平 | 期权隐含波动率 | IV 极高 → 市场预期大波动（常是财报前/恐慌），追高股票风险大；IV 低 → 市场平静 | 需按标的类型归一（杠杆 ETF 天然高 IV） |
| IV 抬升（近月 vs 远月） | 近月 IV 显著高于远月 → 临近事件 | 财报/重大公告临近，方向性买卖要谨慎 | 富途无历史 IV，只能用期限结构相对值 |
| Put/Call OI 比（PCR） | 全链 put OI ÷ call OI | 高 = 对冲盘/偏空重；极端高 + 股价不破位 → 可能是反向/底部信号 | 单一阈值不可靠，看极端与变化 |
| Max Pain | OI 最大行权价 | 到期日股价有被「钉」向该价附近的倾向（短期锚定参考） | 到期前几日才明显，只作参考 |
| 市场定价上涨概率 | ATM call 的 prob_of_profit / delta | 看市场定价的方向与你的判断是否一致 | prob 是模型估计非真实概率 |

## 3. 整体架构（复用现有系统）

```
现有研究层（不动）
  基础池 → Evidence Packet（quote/events/fundamentals/account）
        │
        ▼
期权数据层（新增，程序确定性）       fetch_option_view(code)
  OpenD 期权链 → 全链/近月+次近月 call+put 报价
  → compute_option_view 程序计算 5 指标（纯函数、可单测）
        │
        ▼
证据层（新增，已落地）              make_option_evidence()
  生成 kind='option' 的可引用 evidence，并入该股 packet
  （LLM 只读摘要数值，不自行计算 IV/Greeks）
        │
        ▼
消费层（分阶段开放）
  L2 研究排序：LLM 把期权视角作为一栏参考           ✅ 已接入
  L3 确认台提案：抄底/突破触发时在提案里显示期权视角    ⏳ 计划
  L4 规则硬门：期权指标达到阈值 → 降档/提示（阶段2）    ⏳ 观察后开放
```

## 4. 数据现状（已用探针确认）

- 富途 OpenD 期权行情已通：`get_option_expiration_date` / `get_option_chain` / `get_option_quote`。
- 每标的到期：17 个；每到期行权档：94–130；quote 返回 **38 字段**，含 `implied_volatility`、`delta/gamma/vega/theta/rho`、`open_interest`、`volume`、`prob_of_profit`、`breakeven_point`、`max_pain` 相关字段等。
- `implied_volatility` 是**百分数值**（SOXL 探针 ~122 表示 122%），代码存 `atm_iv_pct`。
- 富途无历史 IV/历史全链 → 无法做 IV 历史分位；v1 用绝对阈值 + 期限结构相对值 + 链内相对。

## 6. 分阶段实施

| 阶段 | 内容 | 状态 |
|---|---|---|
| **P0** | 期权链数据探针，确认覆盖/字段 | ✅ |
| **P1** | 期权视角模块 + 并入研究批次（LLM 参考） | ✅ |
| **P2** | 确认台提案展示：抄底/突破信号触发时，提案卡片附期权视角行（复用 dip/trend monitor 的 context 拼装） | ⏳ 计划 |
| **P3** | 规则硬门（观察 P1 一段时间后）：高 IV 追涨警示 / PCR 极端提示 / 事件临近(IV 抬升)降档；阈值按标的分组 | ⏳ 待样本 |
| **P4** | 影子评估：记录「带期权视角 vs 不带」的候选后续收益，判断是否有增量 | ⏳ 待样本 |

## 7. 风险与注意

1. **期权视角是温度计不是判官**：只用它来「谨慎/验证」，不覆盖趋势与事件判断。
2. **杠杆 ETF 天然高 IV**：SOXL 这类 3x 标的 IV 常 >100%，阈值须按标的分组（semis 3x / 正股 / ETF），不能一刀切。
3. **无历史 IV**：v1 不做历史分位，用「绝对阈值 + 近/远月价差 + 链内 PCR/MaxPain」，避免假装有分位精度。
4. **报价时效**：期权链是快照，过期数据要标 `data_cutoff_at`（沿用现有时间纪律）。
5. **LLM 边界**：LLM 永远不读/算 IV、delta 原始值做判断——只读程序算好的摘要，避免模型对数字幻觉。
6. **不喧宾夺主**：默认影子参考，不改变任何现有买入/风控/确认行为。

## 8. 验证思路

- 影子期：对每个研究候选，同时记录「是否触发高 IV / 极端 PCR」标签，但不拦截；攒 N 批后比较「带该标签买入候选的后续 1/3/5 会话收益」与不带标签的差异。
- 复用 `selection_outcomes` / `run_selection_outcomes` 固定窗口框架，给候选打上 option_view 标签做分组归因。
- 只有出现稳定信号（如高 IV 批次确实表现差）才把 P3 硬门从 `shadow` 拨到 `constrained_action`（沿用权限状态机）。

## 9. Backlog（按价值排序，供后续挑选）

1. P2：确认台提案附期权视角（抄底/突破触发时能直接看到，价值高、改动小）。
2. P3 规则硬门第一档：**高 IV + 追涨** → 提示/降档（对应当前最常踩的「高位追进高波动票」）。
3. 期权视角进 `daily_trend_gate` 同层，作为提示不拦截。
4. IV 归一：无历史分位时，用「该标的全链 IV 中位数」做相对参照，替代绝对阈值。
5. 池子扩展（如 SPY/QQQ 高流动 ETF）前，先跑通现有 8 只。
