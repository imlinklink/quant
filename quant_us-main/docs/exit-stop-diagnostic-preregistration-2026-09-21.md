## 0. 先披露：这份登记**不是盲的**

本假设是**看着 010 的退出分类汇总选出来的**：

```
TIME_EXIT 111 笔 +460,918 USD   STOP 72 笔 −155,494   GAP_STOP 14 笔 −38,438
止损后 60 日内回到入场价的比例 69.88%（描述性）
```

§8.2 要求 D1「在研究区识别一个最值得检验的问题」，而识别必然要用已看到的结果 ——
问题不在于"看过"，在于**看完之后有没有再改口径**。所以这份登记的作用是：把
**改什么、怎么算、什么算支持、什么算不支持**固定在计算之前，并且把"已看过什么"写下来
（§8.4：已查看的区间不得再称为未见样本外）。

**不得**把"止损后反弹"本身当成止损过紧的证据 —— 设计 §3 明列它为不足为证的现象。
它在这里只作**描述**，判定用的是机会级净损益与账户级重放。

## 1. 假设与竞争解释

| | |
|---|---|
| **H3** | 初始固定止损距离 `max(8% × 入场价, 2.5 × ATR14)` 过紧：它在趋势内的正常回撤处离场，牺牲了本可持有到 H60 的趋势收益。 |
| **竞争解释** | 止损的净贡献可能为**正**：它避开的正是继续下跌的交易。要区分两者只能算**两个方向**（§5.4）。 |
| **不主张** | 不加入追踪止损；不调整 H60；不放宽入场或仓位上限。 |

## 2. 唯一改动

**只动止损距离这一处。** 入场、市场门/周线门/日线择时、等待窗、H60 期限退出、费用、
公司行动、五仓上限、单笔风险预算 —— 全部逐字保留。代码位置：`medium_initial_stop`
（研究侧）与 `paper_engine.initial_stop_micro`（影子引擎侧），两者是同一公式。

## 3. 第 1 步：机会级诊断（先做，且先于账户级）

对 010 实际成交的**全部 201 笔**入场，用**同一条价格路径**算两种结局：

- **A 实际**：含止损（按引擎现有跳空/日内止损规则）；
- **B 反事实**：关闭止损触发，持有到 H60 收盘退出；数据不足则标右删失。

**股数保持与 A 相同**（§5.4 要求先算"固定单位风险的机会级结果"）：反事实不重算仓位，
使两臂入场规模完全一致，差异只来自出场。

要报的量：逐笔净损益（USD 与 `net_R`，`net_R = 含费损益 / 冻结的初始风险金额`）、
**最大不利波动 MAE**（入场后最低价相对入场价，% 与 R）、最大有利波动 MFE（仅描述）、
持有期（按参考交易日历、入场日与退出日都算）、反事实下的退出原因分布。
**1× 与 2× 费用都要报。**

三条必须的分解：

1. **全部 201 笔**的两臂净损益差 —— 不是只看被止损的那 86 笔；
2. **被止损的 86 笔**里，"反事实下转盈"与"反事实下仍亏"**两个方向都报**；
3. **未被止损的 115 笔**两臂应当**完全相同** —— 不等就说明反事实实现有误，**先修再算**。

## 4. 第 2 步：账户级筛选

机会级收益差**不能相加**当组合增量（§5.4）：多个机会竞争同一份现金与仓位，延长持有
还会改变后续机会。故用与 010 同一引擎（`paper_engine.step`：真实现金、T+1、公司行动、
五仓上限、回撤阶梯、单笔风险预算）、同一起点，把止损距离按 §5 的登记网格跑一遍账户：

- **是否挤掉后续机会**：`MAX_POSITIONS` / `DUPLICATE_ACTIVE_SECURITY` 拒绝数的变化，
  以及被挤掉的机会清单（不可只报总笔数）；
- **改善是否伴随更大回撤或更肥的尾部**：最大回撤、**最差单笔 `net_R`**、亏损笔的集中度；
- 现金闲置与暴露的变化（**描述**，不是损失结论，§7.2）。

沿用 010 的工程检查：账户不变量、NAV 会计恒等式、重放一致、跨引擎基线对账。

## 5. 第 3 步：冻结单项 challenger（仅在 1、2 都支持时）

**止损距离 = `max(k_floor × 入场价, k_atr × ATR14)`，单一标量放宽**，其余一字不改。

**登记网格（就此固定，看到结果后不得扩大）**：

| 标签 | `k_floor` | `k_atr` |
|---|---:|---:|
| S1.5 | 0.08 | 3.75 |
| S2.0 | 0.08 | 5.00 |

- 仓位按新止损距离**重算以维持原单笔风险预算**（`risk_sized_shares_micro` 的 distance
  变宽 ⇒ 股数自动变少），不额外放宽风险。
- 选择规则沿用已冻结的规则基线协议：MDD ≤ 20% 硬界 → MDD ≤ 18% guardrail → 合格者取
  CAGR 最高；无合格者记 `no_qualified_baseline`。
- **必须新建** `experiment_id` / `study_id`，不得改写 010。

## 6. 判定规则（计算之前固定）

**第 1 步判为"支持"**：全部匹配机会的两臂净损益差 > 0；增量**不集中**（单一证券贡献
≤ 50% 的增量，且剔除最大贡献证券后仍 > 0）；2× 费用下仍 > 0。

**第 2 步判为"支持"**：账户级净增量 > 0；`abs(MDD_challenger) − abs(MDD_baseline) ≤ 0.03`
（§9.3 的回撤预算建议）；2× 费用下仍 > 0 且最差单笔 `net_R` 不劣于基线。

**判为"不支持"**（任一成立即保留原策略）：改善集中在 ≤ 2 只证券或 ≤ 5 笔
（`CONCENTRATED`）；剔除最大贡献证券后转负；回撤超预算或尾部显著更肥（`RISK_REJECTED`）；
两臂无实质差异（`NO_IMPROVEMENT`）。

**明令禁止**：看到结果后扩大网格或加入第二个变量；在同一窗口上反复重试直到出现赢家；
把机会级收益差当组合增量；用"止损后反弹"本身作证据。

## 7. 验证窗口

**探索区间** `2015-01-02 → 2026-08-31` 已被策略研究与本次诊断查看 ⇒ **只能用于定位问题**，
不得作为验证（§8.4）。候选规则冻结后的验证用**事先登记的前向窗口**：注册日之后的第一个
交易日开始，到首个评估点为止；首次评估需 **≥ 30 个独立成熟组 且 ≥ 60 个交易日**，
两者都满足才作判定，否则继续观察或报 `INSUFFICIENT_SAMPLE`。独立组按**证券 × 候选轮次**，
Position 按整笔 trade，多期限不重复计数。
