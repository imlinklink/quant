## 2. 三批各自做了什么、结果是什么

### S1 卖出侧：机械利润保护（预登记 `EXIT-PROTECT-20260921`）

规则：浮盈达 1.0×R0 后启用 `H − 3.0×ATR14` 跟踪线，只收紧、T 收盘算 T+1 生效
（参数不是网格搜的，理由逐条写进登记）。同机会对照 201 笔，**三个控制项全过**
（A 臂逐笔复现账本 201/201 笔出场）。

**机制**：原策略净 R>3 的 34 笔合计 +161.41R，同一批笔在保护线下降到 +95.83R。
保护线把**右尾搬到中间**（长持有→短持有、大赢→小赢），而左尾由初始硬止损封着、没被改善
—— 所以「回吐少了 4.02%」换不来任何风险改善（那 4% 本来就不是尾部损失）。胜率反而升了
（104→113 笔盈利），正是「提高胜率但损害净收益不算达成」的实例。

### B1 买入侧：趋势回撤型抄底信号（预登记 `ENTRY-BOTTOM-20260921`）

规则：`close > MA200 且 MA200 上行` + 从 252 日高点回撤 ≥ `max(3×ATR/价, 10%)` → WATCH →
收盘首次收回 MA20 → 次日开盘执行。**替换的是整个 B3 入场包**（不是「移除日线过滤」，
H-A 不重开）。规则数值在写代码之前就固定在规范里并提交（`d40376a`）。

**入场分解就是结论**：共同成交 7 笔；仅 B **163 笔（+$188,585）**；仅 A **194 笔（+$262,107）**。
抄底信号带来的新成交是正贡献、不是噪声，但它**挤掉**了 B3 更赚的那批 ⇒
**是替代，不是补充**：在五仓、现金不构成约束的账户里，多买一类信号等于少买原来那类。
B 的 362 个信号只有 170 笔成交（容量装不下）。

### L1 LLM 持仓角色（规划 §6）

只开 `hold`/`exit`；技术证据包 22 项程序计算事实（每项带单位·算法版本·as_of·available_at·
来源·缺失原因，缺失时是 `None` 而非 0）；充分性标准独立于新闻质量门。

**最重要的发现**：`validate_position_v2` 对 `reduce`/`exit` 硬性要求「至少引用一条证据」
（`position_v2.py:276-280`），而项目不接公司事件源、市场日报是唯一供给 ⇒
**在有可引用的技术事实之前，EXIT 在结构上不可能通过校验，L 只能恒等于 R**。
技术包构造性地解开了它，并由测试钉死（去掉技术条目，同一个 exit 输出立刻被拒）。
合成输入验证了六条链（零新闻也开门 / 只提供开放动作 / EXIT 能变成改变路径的动作 /
集合外动作降级 / 不给技术包时逐字段不变 / 前视两道闸分别验过）。

**尚无任何 L−R 数字**：§6.3 第二步（真实前向数据 + 真实模型）未做。历史调用含模型知识穿越，
不能当收益证据，所以这个数只能靠前向攒。
