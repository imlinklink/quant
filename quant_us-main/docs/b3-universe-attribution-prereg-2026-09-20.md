# B3 宇宙扩样归因：预登记（草案）

日期：2026-09-20 ｜ 状态：**待评审，未执行**

## 0. 这份文档是什么、不是什么

**是**：一次**归因诊断**的预登记 —— 度量「B3 只用十三只事后挑出的赢家」这件事，
给它的单位暴露收益贡献了多少。

**不是**：验证。理由见 §6：2016–2026 这段历史**已经被查看过**。因此本实验的结论
只能写成诊断，**不得据以调参、放行新策略、或宣称任何策略优势**。

写下这句不是为了保守，是因为仓库里已经有一份做了同样的事、结论 `inconclusive`
的实验（§1.3），它当时没有把这句话说清楚。

## 1. 为什么做这件事

### 1.1 当前的收益缺口是「暴露」而不是「信号」

`RISK-RULE-20260916-001` 的 19 个配置实测（2016-01-05→2026-08-25，$100k，0.2% round-trip）：

| 配置 | CAGR | 平均总暴露 | 单位暴露收益 | MDD | Sharpe |
|---|---|---|---|---|---|
| QQQ（满仓） | 19.48% | 100% | 19.5% | 34.3% | — |
| B3@60@1% ← 冻结基线 | 15.16% | 35.5% | **42.7%** | 13.9% | 1.22 |
| B3@90@1% | 18.20% | 38.4% | **47.4%** | 18.8% | 1.32 |

信号端看着是健康的（11 年只有 1 年下跌、单笔最大赢家只占全部盈利 9.3%），
**是现金拖累把 CAGR 压到 QQQ 之下**。

### 1.2 但那个 42.7% 建立在一个事后挑出的宇宙上

`p2_selection_check.py:35–37` 的 `TECH` 是**硬编码的 13 只**：AAPL / AMD / AMZN / ARM /
CRWV / GOOGL / INTC / LITE / META / MSFT / MU / NFLX / NVDA —— 全是**今天回头挑出来的
十年赢家**，还混进了 CRWV（2025 上市）、ARM（2023 上市）这类**当年根本不存在**的标的。

在这个宇宙上跑动量，42.7% 天然被高估。**我们要量化的就是"高估了多少"。**

### 1.3 已经有过一次同类实验，结论是 inconclusive

`data/tech_holdout/TECH-HIST-20260913-003`：按 IYW ETF 权重预登记 40 只
（规则原文 `no price or return used`）、2016-01-01→2026-06-30、raw-as-of 价：

```
C−A mean_diff = −0.046%   CI [−1.275%, +1.161%]   p = 0.945
years_positive 5/11       eligible 13 / rejected 27
```

那次是买侧 A/B/C setup，不是 B3，**不构成对 B3 的证伪**。但它留下两条必须继承的教训：

1. 预登记规则（不碰价格/收益）是对的，要沿用；
2. **它的质量门把偏差换了一种**：27 只被拒里 24 只原因是 `UNKNOWN_LISTING_DATE` ——
   富途对老公司返回 `1970-01-01` 占位、对近年上市的新股给真上市日，于是这道门
   **实际筛掉了长历史老公司、留下了近期 IPO**。13 只放行里 6 只是 2019 年以后才上市的。
   一个 2016 起的回测只有 7 只覆盖前四年 —— 而"入选"本身与"近期上市"高度相关。

   **所以本实验必须显式检查自己宇宙的上市年份分布，不能重复这个错误。**

**结论：这是一件接线工作，不是数据采购工作。** 唯一挡住它的是 §3。

## 3. 唯一的闸门：24 只的行动历史未经核验

39 只（非 SPY）里 **14 只零条公司行动**：

| 判定 | 证券 | 依据 |
|---|---|---|
| **明确缺失（8 只）** | XOM、PG、ORCL、QCOM、TSM、UNH、SHW、PLD | 均为长期分红公司（PLD 是 REIT），不可能零条 |
| 情有可原（6 只） | ARM、CRWV、NBIS、SNDK、LITE、AXTI | 近年上市/分拆，确实不分红、无拆股 |

**为什么这是硬闸门而不是可容忍的噪声：**

1. **SHW 在 2021-04-01 有 3:1 拆股，这条缺失**。raw 序列会在那天"假摔" 67% ⇒ 回测
   会把它读成暴跌 ⇒ 触发止损 ⇒ **生成假信号**。这是会污染结论的雷，不是偏差。
2. **HON 的拆股比已记录为错**：`price_action_mismatches.csv` 记
   `2026-06-29, split, expected=0.5, observed=0.9157`；另有 3 条分红不匹配。
3. 8 只缺分红 ⇒ 它们的十年回报被系统性低估（年化 1–3%/年，十年累计可观）。
   方向恰好让"宽宇宙"显得更差 —— **但一个你控制不了方向的偏差仍然是偏差**。

**并且这不是新发现**：`research_quality_intervals-v3.csv` 判定的 15 只 `verified`
（＝当前 13 只 TECH ＋ BAC ＋ HD）**正好是行动历史看起来完整的那批**。项目自己的审计
早就划出了这条线，`m2-raw-asof-raw-universe-audit` 也写明「ORCL/QCOM/TSM/UNH 的行动
历史缺口在核验前仍须隔离」。

**所以：不补这 24 只，扩样归因跑出来的数字没有意义 —— 这正是整个项目要避免的那种"看起来在工作"的结果。**

### 3.1 前置工单：补齐行动历史

- **对象**：24 只（8 只明显缺失 ＋ 6 只确认为无非行动但需留证 ＋ HON 比值修正
  ＋ 其余 9 只逐条复核）
- **来源**：权威公开 —— 公司 IR 公告 / SEC EDGAR / 交易所。**不得用 QFQ↔raw 价差反推
  充当核验**（现有 1,601 条正是这样来的，所以它们只能算"候选"）
- **每条记录必须带**：`source_url`、`source_observed_at`、核验方式、核验人/日期
- **验收**：复用 `survivor_sample_audit/price_action_checks.py` 的方法逐条对齐
  raw 与 action 的价格影响，**要求 mismatched = 0**；拆股比值必须精确（HON 那条就是反例）
- **不可覆盖**：新产物另起 run id，旧 `futu-survivor39-20260912` 保留作溯源

## 4. 实验设计（补齐后才可执行）

- **宇宙**：§2 的 `universe_v2` 中 `eligible == True` 且在 `research_quality_intervals`
  内 `verified`（或行动已补齐并转入 verified）的证券
- **策略**：**B3 一个字母都不改**（`entry_rule=b3`、`exit_policy_id=H60`、`single_position_risk_bp=100`）。
  一次只动一个变量：宇宙。
- **窗口**：与冻结基线**同窗同参**，否则不可比
- **三臂对照**（这是本实验的核心信息量）：

  | 臂 | 宇宙 | 时点门 | 回答什么 |
  |---|---|---|---|
  | A（现状） | 13 只硬编码 | — | 基线 |
  | B | 39 只 | 开 | 换成已审计的宽池 + 正确上市日/流动性 |
  | C | 39 只 | **关** | 量化"时点门本身"值多少 |

  B − A = 后视挑选的总贡献；B − C = 时点门单独的效果。
- **判据**：复用 `risk_rule_experiment.py::_select_frozen`（MDD≤20% 硬界 → 优先 ≤18% → CAGR 最高）
- **必须报告**（缺一不可）：CAGR / MDD / Calmar / Sharpe / **单位暴露收益** / 平均暴露 /
  换手 / 年度分布 / top1·top2 赢家集中度 / 逐证券贡献 / **宇宙的上市年份分布**
  （§1.3 的教训）/ 每只证券被 `eligible` 覆盖的 session 数
- **预登记**：跑之前把 manifest 冻结（含代码 hash、数据 hash、参数、判据），
  跑之后**不得改参重跑**

## 5. 结论只能怎么写

- 只能写成：**「后视挑选贡献了 X 个百分点」** 的归因
- 不得写成：策略优势、可放行、样本外证据、未来收益预期
- 必须随结论附上的边界（§6）

## 6. 已知边界（必须随结论一起披露）

1. **仍含幸存者偏差**。用户已明确「不纳入退市样本」，所以池子只能是"今天仍上市"的
   名字。结论限定为「**在所选存续股票内**的条件性结论」，不能外推全市场。
2. **2016–2026 已被查看**。这次不是样本外，是诊断。真正的验证只剩**前向**。
3. **公司行动即便补齐仍是外部来源**，需登记来源与观测时间；若能拿到带原始观测时间的
   权威历史表更好。
4. 富途不提供 ticker 变更历史 ⇒ 改名会表现为新证券。

## 7. 需要拍板的三件事

1. **是否先做 §3.1 的行动补齐？** 不花钱，是纯工作量（约 24 只逐条核）。
   不做则本实验不能跑 —— 跑出来的数字会是错的，而错的方向不可控。
2. **归因结论的用途边界**。建议：仅用于回答"42.7% 这个数字可不可信"，
   **不进入任何选型或放行判断**。
3. **回撤预算**：要不要吃满 20% 硬界（B3@60@1% → B3@90@1%，CAGR +3.0pp、
   Sharpe 1.22→1.32、MDD 13.9%→18.8%、Calmar 1.09→0.97）。
   这是风险偏好决定，不是研究结论，且**与本次归因无关，可以并行定**。

## 8. 执行顺序

```
1. 拍板 §7 的三件事
2. 做 §3.1 行动补齐（前置，硬闸门）→ 验收：mismatched = 0
3. 把补齐后的证券转入 verified 质量区间（新 run id，不覆盖旧的）
4. 冻结本实验 manifest（代码/数据/参数/判据 hash）
5. 跑三臂 A / B / C
6. 一次性打开结果，写归因结论 + §6 边界
7. 登记：仅诊断 / 需要修数据 / 可以进入下一步
```
