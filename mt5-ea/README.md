# SimpleAutoTrader（MQL5 EA）

一个可直接运行的 MetaTrader 5 自动交易 EA：自动看行情、下单，并在下单时把**止盈止损挂在订单上**（经纪商端执行，即使 EA 或电脑断开，止盈止损依然有效）。

当前内置策略是**双均线交叉**（示例，方便替换成你自己的策略），并自带这些风控：

- 每单按余额百分比计算手数（也可切换固定手数）
- 止损、止盈点数可配置（下单时挂上）
- 可选移动止损
- 同品种最大持仓数限制
- 点差过滤（行情点差过大时不交易）
- 交易时段过滤（可按小时限制）
- 当日最大亏损熔断（达到限制自动全部平仓并停止交易）
- 保证金安全检查（余额不足自动降手数或放弃开仓）
- 魔术数字隔离（只管理自己的订单，不影响手动单）

## 安装步骤（Mac）

1. 把 `SimpleAutoTrader.mq5` 复制到 MT5 的 Experts 目录：

   ```bash
   cp "SimpleAutoTrader.mq5" "$HOME/Library/Application Support/net.metaquotes.wine.metatrader5/drive_c/Program Files/MetaTrader 5/MQL5/Experts/"
   ```

2. 打开 MT5，按 `F4` 打开 MetaEditor，在左侧导航里找到 `SimpleAutoTrader.mq5`，按 `F7` 编译（确认没有报错）。
3. 回到 MT5 主界面，在"导航器"(Navigator) → "智能交易系统"(Expert Advisors) 里找到 `SimpleAutoTrader`，拖到图表上。
4. 在弹出的设置窗口里按需修改参数（见下），确定前记得勾选"允许算法交易"。
5. 点击工具栏上的 **Algo Trading** 按钮（确保不是灰色/关闭状态）。
6. 观察"工具箱" → "专家"(Experts) 标签页，应该能看到 EA 的初始化日志和后续的交易记录。

## 参数说明

| 参数 | 默认值 | 说明 |
|---|---|---|
| 交易品种 | 空 | 留空=当前图表品种 |
| 魔术数字 | 20260901 | 用来识别本 EA 的单子 |
| 交易方向 | 多空都做 | 可限制只做多/只做空 |
| 同品种最大持仓数 | 1 | 同时最多持有几个该品种的仓位 |
| 最大滑点 | 20 点 | 超过则不成交 |
| 最大点差 | 30 点 | 点差过大时跳过信号 |
| 交易时段 | 0-0 | 按终端/服务器时间限制，0-0=全天 |
| 快线/慢线周期 | 10/30 | 双均线参数 |
| 手数模式 | 风险百分比 | 或切换固定手数 |
| 每单风险 | 1% | 按止损距离反推手数 |
| 当日最大亏损熔断 | 0 | 0=关闭，如 5 = 当日亏 5% 就全部平仓停止 |
| 止损点数 | 300 | 下单时挂到订单上 |
| 止盈点数 | 600 | 下单时挂到订单上 |
| 移动止损启动/回撤 | 0/100 | 0=关闭；如 200/100：浮盈 200 点后，止损跟随到当前价-100 点 |

## 使用建议

- **先在模拟账户上跑**，确认信号和风控符合预期，再考虑实盘。
- 用 MT5 自带的**策略测试器**(Strategy Tester)可以回测这套双均线参数：
  选择 `SimpleAutoTrader`、品种和时间周期，点击"开始"，可看历史收益、回撤等指标。
- 实盘前把风险参数调小（比如每单风险 0.5%、当日熔断 2%）。
- 长期 24/7 自动交易建议放在一台常开的电脑或 Windows VPS 上跑。

## LLM 人工确认桥接（DeepSeek）

让 DeepSeek 每根新 K 线读一次行情快照、给出交易建议，你在网页或终端里**人工确认后** EA 才下单（带止盈止损）。桥接服务用 Python 标准库实现，**无需安装任何第三方包**。

### 运行流程

```
MT5 EA ──快照──> bridge.py ──> DeepSeek API ──> 建议(pending)
                                                    │
                              你在网页/终端确认 ────┤
                                                    ▼
MT5 EA <──confirmed── 写入 decision.txt ──> 自动下单(带止盈止损)
```

### 第一步：配置 DeepSeek API Key

两种方式任选其一：

```bash
# 方式A：环境变量（每次运行都要设置）
export DEEPSEEK_API_KEY=sk-你的key

# 方式B：配置文件（推荐，只配一次）
cp bridge_config.json.example bridge_config.json
# 然后编辑 bridge_config.json，把 api_key 填进去
```

`bridge_config.json` 里还可以改模型（默认 `deepseek-chat`）、端口、MT5 数据目录等。

### 第二步：启动桥接服务

```bash
cd "/Users/wh1817w/Documents/skills-backup-20260828-165934/mt5-ea/llm_bridge"
python3 bridge.py
```

启动后会自动打开确认网页 `http://127.0.0.1:8787`，终端里也会同步显示建议，支持 `y=确认 n=拒绝 r=重问 q=退出`。

### 第三步：把 EA 挂到图表

1. 更新后的 `SimpleAutoTrader.mq5` 已复制到 Experts 目录，在 MetaEditor 里按 `F7` 重新编译。
2. 把 EA 拖到图表上，确认 `InpUseLLMBridge = true`（默认就是）。
3. 开启 Algo Trading。

之后每根新 K 线：EA 写快照 → 桥接服务问 DeepSeek → 网页出现建议 → 你点"确认下单"或"拒绝" → EA 按确认结果执行。

### 安全设计（重要）

- **LLM 的手数建议仅供参考**：EA 始终用自身的 `每单风险`/`止损点数` 风控来计算实际手数。
- **止损止盈会被双重校验**：桥接服务检查方向对不对、距离合不合理；EA 再按经纪商规则挂单。
- **LLM 或 API 出问题时 EA 不交易**：只显示错误，等桥接恢复或下一根 K 线。
- **当日亏损熔断、移动止损等保护在 LLM 模式下依然生效**。
- **决策全程留痕**：`snapshot.txt`、`decision.txt`、`executed.txt` 都保留在桥接文件夹里，方便复盘。

## 给 LLM 添加技能

桥接服务支持**技能文件夹**：`llm_bridge/skills/` 下的所有 `.md` 文件（下划线开头的除外）会在每次决策前自动注入 DeepSeek 的提示词，相当于给 LLM 配上"随身技能书"。

已自带两个示例技能（可以随意编辑或删除）：

- `01-交易纪律与风控.md`：最高优先级，管住风险和纪律。
- `02-盘面分析方法.md`：趋势、支撑阻力、盈亏比、持仓处理的分析框架。

### 使用方式

1. 在 `llm_bridge/skills/` 里新建或编辑 `.md` 文件，用大白话写清楚规则。
2. 保存即可，下一次决策自动生效（不需要重启桥接服务；点网页上的"重新询问 LLM"可以立即试一次）。
3. 文件按文件名排序注入，编号可以控制优先级（如 `00-`、`01-`）。

### 写技能的建议

- 规则写得越具体越好：给条件、给数值（如"盈亏比至少 1:2"），少用"尽量""大概"。
- 用"必须/禁止/一律"写硬性规则，用"建议/优先"写软性偏好。
- 冲突时 LLM 会按文件顺序和"必须"级别的措辞取舍，所以最重要的纪律放在最前面的文件。
- 如果想复用这个环境里的市场分析技能（信号识别、消息面分析等），告诉我，我可以帮你把相关内容改写成桥接技能。

### 常见问题

- **提示找不到 Files 目录**：在 `bridge_config.json` 里把 `files_dir` 改成你机器上 MT5 的实际路径（Mac 官方版默认路径已内置）。
- **网页打不开**：确认桥接服务还在运行，浏览器访问 `http://127.0.0.1:8787`。
- **一直显示"思考中"或错误**：一般是 API Key 没配好或 DeepSeek 服务暂时不可用，看终端里的报错信息。
- **EA 日志提示快照写入失败**：说明桥接文件夹还没创建，先启动一次 `bridge.py` 即可。

## 替换成自己的策略

只需要改 `GetSignal()` 这一个函数：返回 `1` 表示买，返回 `-1` 表示卖，返回 `0` 表示不动。其余下单、风控、止盈止损逻辑都不用动。
